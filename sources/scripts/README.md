# The scripts

Copies of ELIZA scripts, named by script, year and the identifier the document gives the copy
(the research bench's version and reference in brackets):

- `DOCTOR-1965-TAPE-100.txt`: DOCTOR 1965 (TAPE 100) [DOC65-T100]. The script printed after the
  ELIZA listing in Weizenbaum's papers at MIT (dome.mit.edu, handle 1721.3/201699, file
  02-000311051.pdf), headed `PRINT,T0109,2531,.TAPE.,100 ... 03/06`.
- `DOCTOR-1965-TAPE-102.txt`: DOCTOR 1965 (TAPE 102) [DOC65-T102]. The script printed before the
  listing in the same document, headed `.TAPE.,102`, printed in the same session.

Both transcribed by Anthony C. Hay (github.com/anthay/ELIZA, scripts/), verbatim except for
whitespace; taken from there on 12 October 2026. Nothing in them shows which of the two is the
earlier; the bench does not order them.

DOCTOR as printed in the appendix to Weizenbaum's 1966 paper in Communications of the ACM,
DOCTOR 1966 (CACM) [DOC66], is `../DOCTOR.txt`.

The Weizenbaum materials are released CC0 by the Weizenbaum estate; the transcriptions are CC0.
