# German ELIZA script (Nolan and Hellmund, Chatbot::Eliza 1.08)

A German DOCTOR script by John Nolan and Matthias Hellmund, distributed with the Perl module
Chatbot::Eliza 1.08, 1997.

MACHINE TRANSLATED. The German script is alongside. This is a reading of the script's text, not a
runnable script: the keys, decomposition patterns and substitution lists operate on German input
and are left in German.
