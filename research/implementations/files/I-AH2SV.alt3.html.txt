 <h1><i>Elizabeth</i></h1>
 <h2>An Educational Chatbot for Windows</h2>
 <p>Welcome to the home page of <i>Elizabeth</i>, an automated conversation and natural language processing program designed to provide an enjoyable and easy way in to natural language processing, but with sufficient power to enable it to handle complex grammatical transformations and even resolution theorem-proving, as well as straightforward pattern-match/substitution responses. <i>Elizabeth</i> can be thought of as an adaptation of Joseph Weizenbaum's ELIZA program, in which the various selection, substitution, and phrase storage mechanisms have been enhanced and generalised to increase both its flexibility and its potential adaptability. The system also incorporates analysis tables to show exactly what processing has taken place, thus providing a learning tool that can give insights into some of the fundamental methods and issues of artificial intelligence within an entertaining context.</p>
 <h2>Learning Resources</h2>
 <p>For a full description of the comprehensive learning resources included in the package and advice on getting started, see <a href="elizlearn.htm">Elizabeth</li> Learning Resources</a>.
 <h2>Download Elizabeth 2.04, 2.07, or 2.20</h2>
 <p>This program is freeware for educational use, but please respect the copyright, and ensure that if you pass it on you do so without charge, make clear its authorship, and leave all documentation intact. <i>Elizabeth 2.20</i> is the very latest version, incorporating a number of significant improvements, and including a comprehensive PDF manual of over 80 pages. It is provided as a structured ZIP archive (with the appropriate directory structure stored internally):</p>
 <ul>
  <li><a href="../downloads/elizip2020.zip">Elizabeth for Windows 2.20 (structured ZIP archive)</a></li>
 </ul>
 <p>Previous versions of the software provided documentation through the traditional Windows Help system, which is not standardly supported by <i>Windows</i> 10 and therefore considered obsolete. However these can still be downloaded from the following links: <a href="../downloads/elizip204.zip">Version 2.04</a>; <a href="../downloads/elizip207.zip">Version 2.07</a>. <i>Elizabeth</i> 2.07 incorporated various improvements over 2.04, but without updates to the Help file. Scripts produced with either system will mostly work in the same way with version 2.20, to which users are strongly advised to switch, as this will be maintained into the future.</p>
 <h2>Using the System</h2>
 <p>Having downloaded the ZIP archive, extract it into an appropriate root directory (e.g. "C:\Elizabeth") &ndash; this should contain the files <i>Elizabeth.exe</i> (the executable program file), <i>Elizabeth.pdf</i> (the PDF manual), and <i>Elizabeth.ppt</i> (a PowerPoint which can be used to introduce the system to students). The root directory should also contain two subdirectories, called <i>Illustrative Scripts</i> (a library of standard scripts that can be loaded from the Help menu) and <i>My Scripts</i> (for the individual user's own scripts). Initially, the only file with <i>My Scripts</i> will be the inital illustrative script <i>Elizabeth.txt</i> (which is editable, and automatically executed on startup), but other scripts will be copied there (and thus also become editable by the user) if they are chosen from the Help menu. If the user deletes <i>Elizabeth.txt</i> entirely at any point, it will automatically be replaced by the original illustrative script, so there is never any risk of losing access to this (or the other standard scripts) by incautious editing.</p>
 <p><i>Note for school administrators: see Section 6.4 of the manual if you wish to set the system up so that each user has a "My Scripts" directory in their own area of a network.</i></p>
 <p>To run the program, simply execute <i>Elizabeth.exe</i> (e.g. by double-clicking on the file within Windows explorer). The program will immediately start a conversation &ndash; try responding in the ways shown in the screenshot below, and see what happens!</p>
 <p class="screenshot"><img src="../images/elizabeth220.png" alt="Elizabeth screenshot"></p>
 <p>Now go to the Help menu and choose "Open Help file" (the very first option). When the file opens in your PDF viewer, scroll to Section 1.4, "Illustrative Script and Conversation". This will explain what you have seen.</p>
 <p>Alternatively, you might prefer to read through the PDF manual more systematically, starting from Section 1.1, "Overview of the System".</p>
 <h2>Documentation</h2>
 <p>A <i>PowerPoint</i> presentation is provided in the package, developed from one that was used at the University of Leeds in 2002-03. This presentation is intended to give a straightforward introduction to the system in a manner suitable for private study, or an introductory taught course on Artificial Intelligence or Natural Language Processing. Use <i>PowerPoint</i> to print out handouts (six slides per page) for a useful quick-reference guide.</p>
